# homebrew-tap

Homebrew formulae for jvrsantacruz's tools.

```sh
brew install jvrsantacruz/tap/<formula>
```

The full name trusts this tap for that one formula, as Homebrew 6 asks of taps outside Homebrew.

| Formula | What it is |
|---|---|
| [agent-status](https://github.com/jvrsantacruz/agent-status) | Shows in the tmux window list which AI coding agent is working, waiting for you, or failed |

Each project's release workflow writes its formula to `Formula/`, with the checksums of that
release. Do not edit them here: the next release overwrites them. Report problems in the
project's own repository.
